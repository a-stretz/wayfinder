# Wayfinder Demo Strategy

## Demo Goal

Show that Wayfinder is a strategy and initiative intelligence workspace, not a generic task tracker. The demo should focus on how raw signals become structured initiatives, solution paths, and practical actions.

## Suggested Flow

1. **Start at Home**
   - Position Home as the strategic control surface.
   - Point out priorities, recent signals, emerging patterns, and recommended actions.

2. **Show Patterns and Priorities**
   - Explain that Wayfinder looks across initiatives for repeated friction.
   - Use patterns to show where standard approaches may be needed.

3. **Open an Initiative**
   - Go to Initiatives.
   - Use search or filters briefly.
   - Select one initiative to open the full workspace.

4. **Walk Through the Workspace**
   - Start with the problem and context.
   - Show inputs and signals.
   - Explain scoping analysis before recommendations.
   - Pause on Recommended Path as the recommendation section.
   - Show solution paths and requirements.

5. **Show Decision Priority Behavior**
   - Select a decision priority.
   - Explain whether the recommendation changes.
   - If it does not change, emphasize that the lens changes focus, questions, and future direction.

6. **Show Intake Creating a New Initiative**
   - Open Intake.
   - Enter a raw signal.
   - Generate the simulated structured output.
   - Add it to Initiatives.

7. **Show Patterns Updating Conceptually**
   - Return to Patterns.
   - Explain how repeated signals can reveal reusable playbooks over time.

## Key Talking Points

- Wayfinder is not a task tracker.
- The core value is recommendation clarity.
- The workflow is **Signal -> Initiative -> Solution Path -> Action**.
- Recommended Path makes the next action visible but not premature.
- Decision priorities help leaders test emphasis without relying on numeric scoring.
- Intake is simulated in this prototype; it demonstrates the intended workflow, not real ingestion.
- Patterns and Playbooks turn repeated operational friction into reusable guidance.

## What To Avoid

- Do not describe the prototype as production-ready.
- Do not imply there is a backend, persistence, or real AI analysis.
- Do not frame the dashboard as a task management system.
- Do not discuss sensitive or company-specific information.
